# CollabXAI SME Management

A small ASP.NET Core Web API for managing the SMEs that take part in CollabXAI, a platform where several SMEs train an AI model together while keeping their data in their own environments.

The API lets you register an SME (organisation name and contact email), view them, update them and delete them. It only stores the SME's details, not any of their data.

## Structure

- `CollabXAI.Domain` - the `Sme` entity and the custom exceptions
- `CollabXAI.Applicationsh - the business rules (`SmeService`), DTOs (Data transfer Object) with validation and the interfaces
 CollabXAI.Infrastructure - Entity Framework Core, the `DbContext` and the repository
- `CollabXAI.Api` - the controller, error handling middleware and startup
- `CollabXAI.Tests` - automated unit tests

A request goes controller -> service -> repository -> database. Each layer only uses the one below it through interfaces, and dependency injection connects them.

## How to run

Requires the [.NET 8 SDK](https://dotnet.microsoft.com/download).

```
dotnet build
dotnet run --project src/CollabXAI.Api
```

Then open `http://localhost:5111/swagger` to try the API. The SQLite database (`collabxai.db`) is created automatically on first run.

To run the tests:

```
dotnet test
```

## Endpoints

| Method | Route | Description |
| --- | --- | --- |
| GET | `/api/smes` | list all SMEs |
| GET | `/api/smes/{id}` | get one SME |
| POST | `/api/smes` | register an SME |
| PUT | `/api/smes/{id}` | update an SME |
| DELETE | `/api/smes/{id}` | delete an SME |

Errors: 400 for invalid input, 404 if the SME doesn't exist, 409 if the email is already registered.

## Assumptions

- The ID is generated by the server as a Guid (globablly unique identifier), so the client doesn't send one (trade off is that its bigger than an int ID , however better security and no two ID's will ever be the same)
- Contact emails are unique, and are stored trimmed and in lowercase
- Only SME management is built; the local agents are not part of this version
- No authentication, to keep the scope small
